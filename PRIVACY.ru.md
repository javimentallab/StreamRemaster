## 2. Отсутствие обработки персональных данных в Расширении

Расширение не собирает и не обрабатывает никакие персональные данные Пользователя от имени Поставщика. В Расширении отсутствуют учётные записи пользователей, реклама, средства аналитики и системы отчётов о сбоях, и оно не взаимодействует ни с каким сервером Поставщика; Расширение не содержит и не будет содержать ничего из перечисленного. Никакие данные Пользователя, а также никакие звук и изображения, обрабатываемые Расширением, не поступают к Поставщику. Единственными персональными данными, которые может обрабатывать Поставщик, являются данные, которые Пользователь предоставляет ему по собственной инициативе, обращаясь к Поставщику, как указано в разделе 7.

## 3. Принцип работы Расширения

**3.1. Субтитры с использованием сервера Пользователя.** Когда Пользователь включает субтитры в режиме сервера, Расширение передаёт звук вкладки на адрес сервера, который Пользователь сам ввёл в Расширении, как правило на сервер WhisperLive, установленный на компьютере Пользователя или в его локальной сети, и получает от него субтитры. Указанный сервер устанавливает и контролирует Пользователь, который несёт единоличную ответственность за его настройку и безопасность; Поставщик не имеет доступа ни к этому серверу, ни к звуку.

**3.2. Субтитры на компьютере Пользователя.** Когда Пользователь выбирает транскрибирование на своём компьютере, звук обрабатывается в браузере с помощью видеокарты Пользователя и не покидает компьютер.

**3.3. Плавное видео.** Функция плавного видео обрабатывает изображения видео на странице в браузере с помощью видеокарты Пользователя. Изображения не покидают компьютер и не сохраняются.

## 4. Взаимодействие с третьими лицами

Расширение подключается к сайтам, отличным от сервера Пользователя, только по прямому запросу Пользователя и исключительно в следующих случаях:

- **GitHub (api.github.com).** Только когда Пользователь нажимает «Проверить обновления», Расширение запрашивает у GitHub номер последней опубликованной версии. Запрос не содержит данных о Пользователе или об использовании им Расширения.
- **Hugging Face (huggingface.co).** Только когда Пользователь загружает модель транскрибирования для использования на своём компьютере, Расширение загружает её с Hugging Face.
- **Адреса, введённые Пользователем.** Когда Пользователь добавляет модель плавного видео, указывая её адрес, Расширение загружает её с этого адреса.

Как и при любом подключении к сети Интернет, сайт, к которому подключается Расширение, получает IP-адрес Пользователя и идентификационные данные его браузера. Каждый из этих сайтов обрабатывает указанные данные в качестве контролёра в соответствии с собственной политикой конфиденциальности, за которую Поставщик ответственности не несёт.

## 5. Разрешения

- **Хранилище (storage):** для хранения настроек Расширения в браузере.
- **Захват вкладки (tabCapture и offscreen), только в браузерах на основе Chromium:** для получения звука вкладки, на которой Пользователь включает субтитры, исключительно после того, как Пользователь нажмёт кнопку Расширения на этой вкладке.
- **Активная вкладка и выполнение скриптов (activeTab и scripting), только в браузерах на основе Chromium:** для отображения субтитров и применения плавного видео на вкладке, на которой Пользователь нажал кнопку Расширения.
- **Доступ к веб-сайтам (<all_urls>):** в Firefox — для чтения звука и видео страницы в целях субтитров и плавного видео. В браузерах на основе Chromium это необязательное разрешение, которое Расширение запрашивает только в том случае, если Пользователь отмечает флажок, включающий плавное видео автоматически на любом веб-сайте.

## 6. Данные, хранящиеся в браузере

Расширение хранит в хранилище браузера Пользователя свои настройки (адрес сервера, модель, языки, размер и положение субтитров, параметры плавного видео), модели плавного видео, добавленные Пользователем, и модели транскрибирования, загруженные Пользователем для использования на своём компьютере. Эти данные остаются в браузере Пользователя, не передаются Поставщику и удаляются при удалении Расширения; модели также можно удалить в настройках Расширения. Если Пользователь включает функцию сохранения субтитров, при их остановке на компьютер Пользователя загружается файл `.srt`, который остаётся в распоряжении Пользователя.

## 7. Данные, содержащиеся в обращениях Пользователя

Когда Пользователь обращается к Поставщику по электронной почте, Поставщик обрабатывает адрес электронной почты Пользователя, его имя, если оно указано, и содержание сообщения. Когда Пользователь создаёт запрос (issue) на GitHub, такой запрос является публичным и подпадает под действие условий и политики конфиденциальности GitHub.

В соответствии с требованиями статьи 13 ОРЗД предоставляется следующая информация:

- **Цель:** рассмотрение вопроса, запроса или обращения Пользователя.
- **Правовое основание:** согласие Пользователя, выраженное путём обращения к Поставщику (подпункт (a) пункта 1 статьи 6 ОРЗД), а при осуществлении прав, указанных в разделе 8, — выполнение юридической обязанности Поставщика (подпункт (c) пункта 1 статьи 6 ОРЗД).
- **Срок хранения:** время, необходимое для рассмотрения обращения, а затем — срок исковой давности по требованиям, которые могут из него возникнуть. По истечении этого срока данные удаляются.
- **Получатели:** данные не раскрываются третьим лицам, за исключением случаев, предусмотренных законом. Услуги электронной почты Поставщика предоставляет Google, действующая в качестве провайдера услуг.
